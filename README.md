# Student Performance Analysis 📊

A Python data analysis project that explores student performance and identifies patterns in academic scores and study hours.

## 📌 Project Overview

This project analyzes student performance in three subjects:

- Mathematics
- Science
- English

The project calculates average scores, identifies the top-performing student, and visualizes student performance using a bar chart.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
